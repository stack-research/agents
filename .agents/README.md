# Agent Skills (project scope)

Project-scoped skills in this repo live under **`.agents/skills/`**, matching the **“Where to scan”** guidance for cross-client interoperability in [Adding skills support — Where to scan](https://agentskills.io/client-implementation/adding-skills-support#where-to-scan) (project scope: **`<repo>/.agents/skills/`** alongside any client-native `…/skills/` path). The [format spec](https://agentskills.io/specification.md) defines what goes *inside* each skill directory; it does not mandate the parent path on disk.

This is **not** the Python runtime package **`local_agents/`**.
